# 9inetales — brand kit and waitlist prototype

Review draft, September 2026. Static HTML/CSS/JS with no application dependencies.

- `dist/index.html`: reader/creator waitlist prototype.
- `dist/brand.html`: visual brand guide, downloadable assets, typography, and live mobile views.
- `dist/privacy.html`: prototype-specific disclosure.
- `dist/assets/logos/`: 9 outlined SVG exports.
- `brand/`: original logo, concept-art provenance, tokens, copy, and review plan.

The signup demonstrates validation, consent, role selection, and confirmation without collecting, retaining, or sending email addresses. No live mailing list exists. See `brand/REVIEW-PLAN.md` for production requirements.

Local preview: serve `dist/` with any static HTTP server. The Sites manifest identifies a private review site; publishing it does not make it a public waitlist.

The logo family is a proposed vector redraw, not an exact trace of the original. Concept illustration is AI-generated and explicitly labelled. Founder approval, name clearance, live collection, and launch-specific policies remain pending.
